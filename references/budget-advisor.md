# 预算智能建议系统

## 核心公式

> **建议预算 = 阶段基准 × 关系深度系数 × 场景系数 × 历史修正**

---

## 一、阶段基准预算

> 📌 **权威数值定义见 `references/stages.json`**（字段 `budget_range` / `median`）。下表为衍生说明，修改阶段预算只需改 `stages.json` 一处。

按关系阶段给出推荐预算区间：

| 阶段 | 基准区间 | 中位数 | 说明 |
|------|----------|--------|------|
| **追求期** | ¥80 - 300 | ¥180 | 低压力为主，不宜过重 |
| **热恋期** | ¥200 - 800 | ¥400 | 仪式感优先，价格适中 |
| **稳定期** | ¥300 - 3000 | ¥800 | 品质优先，跨度大 |
| **新婚期** | ¥1000 - 10000 | ¥3000 | 承诺级，可大件 |
| **周年纪念** | ¥300 - 5000 | ¥1000 | 按年数递增 |
| **长期陪伴** | ¥200 - 3000 | ¥600 | 贴心 > 价格 |

---

## 二、关系深度系数

根据交往时间调整基准预算：

| 交往时长 | 系数 | 说明 |
|----------|------|------|
| < 3 个月 | 0.7 | 刚认识，不宜贵重 |
| 3-6 个月 | 1.0 | 标准热恋期 |
| 6-12 个月 | 1.2 | 稳定升温 |
| 1-3 年 | 1.5 | 深度稳定期 |
| 3-5 年 | 1.3 | 趋于务实，不追求价格 |
| 5-10 年 | 1.2 | 回归贴心 |
| > 10 年 | 1.0 | 长期陪伴，健康/体验类 |

> 计算方式：`关系深度系数 = (log10(交往月数+1) × 0.5 + 0.5)`，clamp 在 [0.7, 1.5]

---

## 三、场景系数

不同送礼场景有不同的预算预期：

| 场景 | 系数 | 说明 |
|------|------|------|
| 表白/求婚 | 2.0 | 最高仪式感 |
| 春节/圣诞节 | 1.8 | 重大节日 |
| 情人节/七夕 | 1.5 | 核心浪漫节日 |
| 周年纪念 | 1.3 × 年数修正 | 每年递增 |
| 生日 | 1.3 | 个人重要日子 |
| 新婚/结婚纪念 | 1.5-3.0 | 特殊仪式 |
| 母亲节/父亲节 | 1.0 | 心意 > 价格 |
| 道歉/补偿 | 0.8-1.2 | 诚意优先 |
| 日常惊喜 | 0.5 | 无压力小惊喜 |
| 探访/慰问 | 0.6-0.8 | 心意为主 |

---

## 四、历史修正

根据画像中的 `gift_history` 调整预算建议：

| 历史记录 | 修正规则 |
|----------|----------|
| 无历史记录 | 使用默认基准 |
| 历史 < 3 次 | 取历史平均值 ± 20% |
| 历史 3-10 次 | 取历史平均值 + 15%（逐年递增） |
| 历史 > 10 次 | 取历史中位数，不强制递增 |
| 收到正面反馈的礼物 | 同类品类预算 +10% |
| 收到负面反馈的礼物 | 该品类预算 -20% 或淘汰 |
| 用户主动设置 `budget_habit` | 以用户设置为准 |

## 六、预算与品类匹配

每个建议预算对应若干品类方向（仅供 Agent 内部参考，**绝对禁止询问用户选择**）：

### L1 档（< ¥100）
- 鲜花小束（满天星/向日葵 5-9 朵）
- 手写明信片 + 小零食
- 定制钥匙扣/冰箱贴
- 热饮券/书店咖啡券
- 手工饼干/巧克力

### L2 档（¥100-300）
- 鲜花标准束（粉玫瑰/郁金香 9-11 朵）
- 香氛蜡烛/精油套装
- 设计感文具（笔记本/钢笔套装）
- 烘焙/手作体验课
- 她提过的小需求（鼠标/手机壳/暖手宝）

### L3 档（¥300-800）
- 鲜花精品束（19-33 朵 + 配花）
- 香水小样套装或入门香
- 首饰入门款（银饰/合金）
- 品质零食礼盒
- 体验类（展览/电影/SPA）

### L4 档（¥800-2000）
- 鲜花豪华束（33-66 朵 + 礼盒）
- 品牌香水/香氛
- 品质首饰（K金/珍珠）
- 设计师单品（包包/配饰）
- 旅行/周末度假

### L5 档（¥2000-5000）
- 定制首饰（刻字/生辰石）
- 高端护肤品套装
- 数码好物（美容仪/相机）
- 海外旅行/度假
- 定制画像/艺术品

### L6 档（> ¥5000）
- 求婚戒指/对戒
- 高端珠宝
- 私人定制服务
- 海外婚礼/仪式
- 投资级礼物（手表/艺术品）

## 七、预算降级/升级建议

### 降级建议（用户预算低于推荐区间）
> "当前预算低于推荐区间，建议选择 **心意品类** 替代：
> 1. 手写信 + 小束鲜花（¥80-150）
> 2. 她一直想要但不贵的小物件（如耳机/台灯）
> 3. 自己动手做的礼物（手作/烘焙/绘画）
> 低预算的关键是 **心意浓度 > 价格**"

### 升级建议（用户预算高于推荐区间）
> "预算充足，可以考虑 **仪式升级**：
> 1. 将花束升级为更高规格（如 33 朵 → 99 朵）
> 2. 搭配高端品牌单品
> 3. 加入体验环节（如约会/旅行）
> 4. 选择可长期使用的品质物品
> 高预算的关键是 **持久价值 > 一次性消费**"
