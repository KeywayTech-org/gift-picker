# HTML 报告规范

## 生成方式

1. 读取 `assets/report-template.html` 作为骨架（单文件，Chart.js 走 CDN，断网时评分条为纯 CSS 兜底仍可读）。
2. 替换模板中的占位符（见模板内注释），输出为工作区 `gift-report-<YYYYMMDD-HHmm>.html`。
3. 用 present_files 交付。

## 页面结构（自上而下）

1. **页头**：标题（如"给 <昵称> 的 <场景> 礼物清单"）、生成日期、预算区间、候选数。
2. **摘要区**：最推荐 Top1 一句话结论 + 总览雷达图（各候选四维对比）。
3. **礼物卡片列表**（按排序，每卡包含）：
   - 礼物名称 + "最推荐"角标（仅 Top1）
   - 礼物图片（抓取的主图 URL；失败用内置占位 SVG）
   - 总分大数字 + 四维评分条（价格/质量/优质好评度/差评率反向）
   - 画像匹配度进度环 + 命中点标签（如「她的本命色」「同品牌护肤」）
   - AI 详细分析：推荐理由（3~5 条）、与画像的逐项匹配说明、注意事项（含差评提炼的风险点）
   - 价格信息：最低到手价（大字）+ 置信度徽标（高/中/低）
   - 多渠道比价表：渠道 | 价格 | 店铺/来源 | 采集时间 | 购买链接（`<a target="_blank">`）
4. **页脚**：数据来源声明（各渠道 + 采集时间）、置信度说明、"价格波动请以实际页面为准"免责。

## 数据与样式要求

- 中文站内价格一律 `¥`，保留到元或角。
- 差评风险点必须如实呈现，不得只报喜。
- 缺失数据显示"—"并降低置信度徽标，禁止用估算值冒充实测值。
- 移动端可读：卡片单列自适应，模板已内置响应式，勿删 viewport meta。
- 所有购买链接使用采集到的原始 URL，不添加任何推广参数。
