# HTML 报告规范

## 生成方式

1. 读取 `assets/report-template.html` 作为骨架（单文件，Chart.js 走 CDN，断网时评分条为纯 CSS 兜底仍可读）。
2. 替换模板中的占位符（见模板内注释），输出为工作区 `gift-report-<YYYYMMDD-HHmm>.html`。
3. 用 present_files 交付。

## 安全：HTML 转义（硬性要求）

所有写入模板占位符的数据**必须**经过 HTML 转义，防止 XSS 注入：

```python
import html
safe_value = html.escape(original_value)
```

**必须转义的字段**：
- `{{GIFT_NAME}}` - 商品名称
- `{{PRICE_MIN}}` - 价格（数字但仍需转义以防异常值）
- `{{RANK}}` - 排名
- `{{CONF_TEXT}}` - 置信度文本
- `{{MATCH_TAGS}}` - 匹配标签
- `{{REASON_LIST}}` - 推荐理由列表项
- `{{MATCH_LIST}}` - 匹配点列表项
- `{{RISK_NOTES}}` - 风险提示
- `{{PRICE_ROWS}}` - 比价表行（渠道名、店铺名、采集时间）
- `{{TOP1_SUMMARY}}` - Top1 摘要
- `{{SOURCES_NOTE}}` - 数据来源说明
- `{{STAGE_NAME}}` - 关系阶段名称
- `{{STAGE_REASON}}` - 阶段适配理由
- `{{FLOWER_BLOCK}}` - 花语/朵数区块（完整 HTML 片段，需整体转义）
- `{{SEASON_NAME}}` - 当前季节名称
- `{{SEASON_REASON}}` - 季节适配理由
- `{{BUDGET_REASON}}` - 预算合理性分析
- `{{BUDGET_BOX}}` - 预算建议区块（摘要区，完整 HTML 片段）
- `{{SEASON_BOX}}` - 季节适配区块（摘要区，完整 HTML 片段）
- `{{CATEGORY_COMPARE}}` - 多品类对比区块（摘要区，完整 HTML 片段）

**可跳过转义的字段**（模板级控制，非用户输入）：
- `{{RADAR_DATA}}` - JSON 数据（直接嵌入 `<script>`，必须确保是合法 JSON）
- `{{S_PRICE}}`, `{{S_QUALITY}}`, `{{S_PRAISE}}`, `{{S_LOWBAD}}`, `{{S_STAGE}}` - 评分数字
- `{{PAGE_TITLE}}`, `{{GEN_DATE}}`, `{{BUDGET}}`, `{{GIFT_COUNT}}` - 页面元信息

## 页面结构（自上而下）

1. **页头**：标题（含关系阶段徽章）、生成日期、预算区间、关系阶段、候选数。
2. **摘要区**：
   - 最推荐 Top1 一句话结论
   - 总览雷达图（各候选五维对比）
   - **💡 预算建议区块**（蓝色主题）：阶段基准 × 关系系数 × 场景系数 = 建议区间
   - **🌿 季节适配区块**（橙色主题）：当前季节推荐花材和品类
   - **📊 多品类对比网格**：3-5 种不同品类横向对比卡片
3. **礼物卡片列表**（按排序，每卡包含）：
   - 礼物名称 + "最推荐"角标 + **关系阶段徽章**
   - 礼物图片（抓取的主图 URL；失败用内置 SVG 占位图）
   - 总分大数字 + **五维评分条**（价格/质量/优质好评度/差评率反向/**阶段适配度**）
   - 画像匹配度标签（含阶段适配标签）
   - **💡 为什么适合当前阶段**：阶段适配理由区块（紫色主题）
   - **🌿 季节适配理由**：当前季节为什么适合这个礼物（橙色主题）
   - **💰 预算合理性**：价格匹配阶段定位的分析（蓝色主题）
   - **🎯 AI 分析 · 推荐理由**：3~5 条推荐理由
   - **🌸 花语与朵数建议**（仅鲜花品类）：花品种+花语+朵数建议+注意事项
   - **👤 与她的匹配点**：画像逐项匹配说明
   - 注意事项（含差评提炼的风险点）
   - 价格信息：最低到手价（大字）+ 置信度徽标（高/中/低）
   - 多渠道比价表：渠道 | 价格 | 店铺/来源 | 采集时间 | 购买链接
4. **页脚**：数据来源声明、置信度说明、关系阶段说明。

## 关系阶段与花语模块

### 阶段徽章与理由

每个卡片必须包含关系阶段徽章和阶段适配理由：

- `{{STAGE_NAME}}`：阶段中文名（如"热恋期"、"稳定期"）
- `{{STAGE_REASON}}`：为什么这个礼物适合当前阶段，格式：
  > "你们正处于 [阶段名称]，这款礼物的 [特性/价格/寓意] 符合 [阶段] 的送礼原则，[具体理由]。"

### 花语与朵数区块

当候选为鲜花品类时，`{{FLOWER_BLOCK}}` 填充完整的 HTML 区块：

```html
<div class="flower-box">
  <h4>🌸 花语与送花建议</h4>
  <div class="flower-item"><span class="label">花卉：</span>{{花品种}}（{{颜色}}）</div>
  <div class="flower-item"><span class="label">花语：</span>{{花语}}</div>
  <div class="flower-item"><span class="label">推荐朵数：</span>
    <span class="flower-quantity">{{朵数1}}朵 · {{含义1}}</span>
    <span class="flower-quantity">{{朵数2}}朵 · {{含义2}}</span>
  </div>
  <div class="flower-item"><span class="label">适合场合：</span>{{场合}}</div>
  <div class="flower-warn">⚠️ {{注意事项}}</div>
</div>
```

非鲜花品类时，`{{FLOWER_BLOCK}}` 为空字符串。

花语和朵数数据来源：`references/flower-guide.md`

## 数据与样式要求

- 中文站内价格一律 `¥`，保留到元或角。
- 差评风险点必须如实呈现，不得只报喜。
- 缺失数据显示"—"并降低置信度徽标，禁止用估算值冒充实测值。
- 移动端可读：卡片单列自适应，模板已内置响应式，勿删 viewport meta。
- 所有购买链接使用采集到的原始 URL，不添加任何推广参数。
- 图片加载失败时，模板自动显示 SVG 占位图 + 虚线边框错误样式。
- 断网时 Chart.js 无法加载，雷达图区域显示友好提示，评分条仍可正常阅读。
- 新增的"阶段适配"评分条使用紫色主题（与其他维度的粉色区分）。
- 关系阶段徽章出现在页头和每个卡片的右上角。
