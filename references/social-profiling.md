# 社媒 ID 一键画像（喜好报告流程）

用户只需提供对方的平台 ID/账号名（小红书号、微博号、抖音号、B站号等），自动检索其公开媒体内容，分析喜好，生成**不落盘的喜好报告**，经用户确认后再进入礼物检索。

## 流程总览

```
用户提供 ID → 解析平台 → 拉取公开数据 → 喜好分析 → 对话内输出喜好报告（不落盘）
→ 用户确认/纠正 → （询问是否存入画像）→ 进入礼物检索
```

## 各平台数据获取方式

数据获取**只读公开内容**，统一走免费路径：

- **免费默认（browser-use）**：用 browser-use 打开该平台公开主页/搜索页，读取其发布、公开收藏（若公开）、评论与相册；无需任何付费 Key，零依赖、开箱即用。

| 平台 | 免费路径（browser-use） |
|---|---|
| 小红书 | 打开其公开主页，读取发布笔记、公开收藏（若公开）、笔记评论区 |
| 微博 | 打开公开主页读取原创微博、相册 |
| B站 | 打开公开主页读取投稿 / 公开收藏夹 |
| 抖音 | 搜索引擎 `site:douyin.com <ID>` + browser-use 打开公开主页（只读）；不可得则回退截图/速写模式 |

采集范围建议：最近 50~100 条发布 + 公开收藏，足够画像，不必翻全量。原始数据摘要写入 skill 目录 `memory.md`（任务结束随例行清理删除）。

## 喜好分析维度

从笔记/微博的文本、图片、标签、收藏行为中提炼，每项标注证据来源与置信度（高/中/低）：

1. **色系偏好**：发布图片主色调、穿搭色、收藏内容色系
2. **穿衣风格**：穿搭内容风格归类（简约/甜美/复古/运动/多元）
3. **品牌信号**：提及或收藏的护肤/美妆/服饰品牌，按出现频次排序
4. **兴趣标签**：内容主题分布（如 咖啡探店 30%、健身 20%、宠物 15%…）
5. **种草清单**：收藏/点赞中的商品类内容——这是"她想要但还没买"的最强信号
6. **生活方式线索**：养宠、健身、旅行、手作等影响礼物方向的信息
7. **雷区推断**：明确表达过不喜欢/避雷的内容

## 喜好报告（不落盘，硬性）

- **只在对话中输出**，禁止写成 HTML/md 文件落盘；原始采集摘要仅存 `memory.md`（任务末清理）。
- 报告结构：账号确认信息 → 7 维度分析（每条带证据示例与置信度）→ 推导出的礼物方向建议 3~5 个 → 待用户确认的问题（如"分析显示她偏爱 X，准确吗？"）。
- 报告末尾用交互式提问让用户：① 确认/纠正分析结论；② 选择是否将提炼结果存入持久画像（存入才调 `profile_manager.py set`，默认不强制）。
- 用户确认后，将确认版喜好并入本次任务的搜索关键词，进入礼物检索阶段。

## 合规与隐私红线

- 仅分析**公开**内容；不尝试登录对方账号、不采集私密收藏/粉丝列表/联系方式。
- 分析结果仅服务于本次礼物挑选，不用于其他用途；对话报告中不展示对方可精确定位的信息（如常驻地址推断）。
- 若检索不到该 ID 或主页设为私密，如实告知并回退到截图/速写模式，禁止编造分析。
